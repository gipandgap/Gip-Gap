# Gip&Gap

Production-ready foundation for the Gip&Gap commercial website.

## Stack
- Next.js 15 App Router
- React 19
- TypeScript strict
- Tailwind CSS
- Framer Motion
- Lucide React
- Next Image optimization

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm start
```

## Important
Replace placeholder contact details and add the final architectural hero image under `public/images/` before production launch.
